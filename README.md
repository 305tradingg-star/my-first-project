# UI UX Pro Max Skill Installation

This project has the **UI UX Pro Max Skill** installed, which provides design intelligence for building professional UI/UX across multiple platforms.

## Features

- 79 searchable UI styles including glassmorphism, claymorphism, and minimalism
- 192 color palettes aligned with product types
- 74 curated font pairings from Google Fonts
- 192 industry-specific reasoning rules for automated design system generation
- Support for 22+ frameworks (React, Vue, Tailwind, SwiftUI, Flutter, and more)

## Using the Skill

The UI UX Pro Max Skill is automatically available in your Claude Code environment. You can use it to:

- Generate design systems for your industry
- Get AI-powered design recommendations
- Access pre-designed UI components and styles
- Learn best practices for your specific platform

## Installation Reference

- **Repository**: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **Skill Configuration**: `.claude/settings.json`

## Requirements

- Python 3.x (for search functionality)
- Claude Code environment with skill support enabled
